# 企业 Agent 与钉钉 ONE 案例

## 一句话结论

[[概念_企业Agent]] 的难点不在聊天，而在上下文、权限、工具调用、失败兜底和真实工作闭环。[[项目_钉钉_ONE]] 的价值在于暴露了企业 AI 从愿景进入泥地时的复杂性。

## 企业 Agent 的必要条件

1. 知道组织里的人、群、角色、项目和上下文。
2. 能调用真实工具，而不是只生成建议。
3. 有权限、审计、回滚和失败恢复。
4. 能处理例外、模糊责任和跨系统信息。
5. 从小闭环开始稳定交付，再谈平台化。

## 钉钉 ONE 的案例价值

ONE 的目标是成为 AI 工作入口，但它同时遇到了：

- To C 入口和 To B 深流程之间的冲突。
- 移动端轻处理和复杂工作闭环之间的冲突。
- 组织发信人立场和用户收信人体验之间的冲突。
- 发布会终局叙事和真实小闭环能力之间的冲突。

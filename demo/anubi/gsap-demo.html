GSAP 能做什么

⚡

gsap.to() / from()

核心补间动画 — 控制 duration、easing、delay，支持任意 CSS 属性和 transform。

🎬

Timeline 序列

用 gsap.timeline() 编排复杂动画序列 — 支持 position parameter、labels、嵌套。

📜

ScrollTrigger

滚动驱动动画 — 支持 pin 固定、scrub 擦洗、trigger 触发、snap 吸附。

✨

SplitText

逐字、逐行文本动画 — 配合 stagger 实现电影级文字入场效果。

🔄

Flip Plugin

状态间平滑过渡 — 记录 DOM 状态变化，自动创建中间动画。

⚛️

React / Vue / Svelte

框架原生支持 — useGSAP hook、自动 cleanup、SSR 兼容。

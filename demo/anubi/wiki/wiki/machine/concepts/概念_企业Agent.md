# 企业 Agent

企业 Agent 是能够在企业系统中基于上下文理解任务、调用工具、执行流程并推进结果的 AI 系统。它不同于只生成回答的聊天机器人，重点在“能否安全做事”。

## 核心能力

- 理解组织上下文：人、群、项目、客户、日程、会议、文档和历史消息。
- 调用真实工具：审批、日程、待办、表格、文档、低代码、CRM 等。
- 遵守权限和边界：知道能看什么、能改什么、能代表谁行动。
- 处理失败：出错后能解释、回滚、交接或请求人类确认。
- 形成执行闭环：不仅生成建议，还能推动事项完成。

## 为什么难

企业软件中的真实工作不干净：信息散落、责任模糊、流程有例外、权限有边界、用户有情绪。Agent 要进入这些场景，不能只靠发布会 demo 或聊天框。

[[置身钉内]] 对 [[项目_钉钉_ONE]] 和企业 Agent 的判断是：要先打赢小闭环——消息能否处理、日程能否闭环、会议能否变待办、知识问答是否可靠——再谈 Agent OS。

## 设计原则

1. 先从高频、低风险、边界清晰的小场景开始。
2. 每个动作都要有上下文、权限、审计和失败兜底。
3. 不要为了短期高分，把真实世界削成适合评测的小题。
4. Agent 平台化之前，先证明单个 Agent 能在真实流程里稳定交付。

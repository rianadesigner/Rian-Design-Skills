**用途：** 作为 **vibe-design / AI 生成界面** 时的语义设计基线：颜色、排版、组件规则与 token 命名与本文保持一致。

## 1. Visual Theme & Atmosphere

- **气质：** 偏 **B 端 / 生产力** 的说明文档页：大量 **表格、规则列表、示意图**，信息密度中高，强调 **可读性** 与 **规范可执行性**。
- **背景：** 以 **浅灰白底**（如 `#f2f3f5`、`#f8f8f8`、`#e4e6ed`）与 **纯白区块**（`#ffffff`）交替，形成分区而不抢眼。
- **主色倾向：** **靛蓝 / 品牌蓝**（如 `#5057f6`、`#6685ff`、`#2944d9`）用于主行动点与强调；**近黑**（`#111111`、`#000614`）用于正文与标题。
- **语义色：** **红**（`#f23c3c` 一类）用于错误 / 危险提示；中性灰阶（`#5f6471`、`#8d93a1`、`#cccccc`）用于次要信息与分割线。

## 3. Typography Rules

- **西文 / 数字：** **SF Pro Display · Regular** 用于大标题与长正文（如 48px 级说明、32px 级小节）。
- **中文：** **PingFang SC** — **Regular** 与 **Medium** 混排；表格表头、按钮标签等偏 **Medium**（如 28px / 24px）。
- **层级（从画布抽样）：**
  - 文档主标题：**约 100px**（展示用「按钮」二字）。
  - 英副标「Button」：**约 48px**。
  - 规则区标题 / 小节：**约 48px / 32px**。
  - 表格与规范说明：**约 32px / 28px / 24px**（随区块略降）。
- **规则：** 按钮内文案 **最多五个字**；字号 / 字重与 token `fontSize`、`fontWeightStrong` 对齐（见画布「元素」表）。

## 4. Component Stylings

### 按钮（Button）

- **形状：** 小圆角文档写 **`borderRadius` = 4px**（与「圆角」行一致）；若其他页面统一 8px，以实现稿为准。
- **结构：** **文本**（必） + **可选图标**（左 `start` / 右 `end`，与 Ant Design 图标名一致，如 `UploadOutlined`、`DownloadOutlined`）。
- **尺寸（文档表）：**
  - **Large：** 高度 **36px**，左右内边距 **20px**，图标与文案间距 **4px**。
  - **Default（中）：** 高度 **32px**，左右 **16px**，间距 **2px**。
  - **Small：** 高度 **24px**，左右 **8px**，间距 **2px**。
- **类型：** Primary / Default / Text / Link（文档示例表）；视觉随 **Type + State** 变化。
- **状态：** Default、Hover、Pressed、Loading、Focused、Disabled、Danger；Loading 使用 **`Loading3QuartersOutlined`** 左侧图标。
- **描边：** **1px**，随属性为无 / 实线 / 虚线。

### 文档页组件

- **分割线：** 1px 高，浅灰（见 `#e4e6ed` 类）。
- **表格 / 规范块：** 顶栏 **示例 / 功能 / 描述** 或 **属性名 / 变量 / 描述** 三列式；行距宽松，便于扫读。

---

## 5. Layout Principles

- **版心：** 左侧 **约 500px** 导航区 + 右侧 **约 2118px** 正文栏（以节点 `0:30` 子级尺寸为参考）。
- **留白：** 区块之间用 **分割线 + 垂直间距** 分段；规则区采用 **标题 + 多列文字**（如「简一性原则」+ 说明）。
- **栅格：** 示意图区常见 **1080 宽** 画板示意 + 标注线；保持 **左对齐** 阅读动线。

---

## 6. Content Rules（自文档摘录，供生成文案时遵守）

- 同一组 **主按钮仅 1 个**；主按钮 **不得居中**；多按钮时 **左主右副**，优先级从左到右递减。
- 图标与 **场景** 绑定需一致（同场景同位置、同 icon token）。

---

## 7. For vibe-design（提示用短清单）

生成新界面时请携带：

1. **主色：** 靛蓝系（`colorPrimary` 一类），危险操作用 `colorError`。  
2. **背景：** 浅灰分区 + 白卡片；正文 `#111111`。  
3. **字体：** 中文 PingFang SC，英文 SF Pro；标题大、正文 32/28/24 阶梯。  
4. **按钮：** 4px 圆角（或设计系统统一值）、三档高度 36/32/24、主按钮唯一、左对齐 CTA。  
5. **实现：** 颜色与字重 **优先 token / 变量名**，避免硬编码脱离本规范。
